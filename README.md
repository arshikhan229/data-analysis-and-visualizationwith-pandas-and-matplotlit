📁 data/              → Sample CSV files (e.g. sales_data.csv)
📁 notebooks/         → Jupyter notebooks for each chapter
📁 scripts/           → Python scripts for reusable code
📁 visuals/           → PNGs of all charts and graphs
📄 requirements.txt   → Libraries to install
📄 README.md          → You're here!
🚀 Getting Started
bash
# Clone the repo
git clone https://github.com/arshikhan229/data-analysis-book.git
cd data-analysis-book

# Install dependencies
pip install -r requirements.txt

# Run the sample script
python scripts/sales_analysis.py
